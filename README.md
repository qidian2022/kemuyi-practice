# 稳稳过 科目一练习 @qi_dian

适合电脑和手机浏览器的科目一刷题网页。提供全量题库（1650 道去重题）、C1/C2 精简（300 道原题精选）和“我的收藏”。精选题来自全量题库，同一道题在两个入口共用答题记录与收藏。

## 开始使用

在 macOS 上，安装 Node.js 后可双击 `启动刷题网页.command`。首次启动会自动安装项目依赖，并在浏览器中打开本地页面；练习期间请保持终端窗口开启。

也可以在终端运行：

```bash
npm ci
npm run dev
```

打开终端显示的地址。网页需要通过本地服务运行，不能直接用 `file://` 打开 `index.html`。

## 练习与记录

- 题目按随机顺序出现。答对后显示反馈，约 1 秒后自动进入下一题；答错后自动显示正确答案和解析，停留在当前题，并自动加入收藏。也可以手动收藏。
- 题干、选项、答案和配图完全一致的原题副本合并为一道；旧副本的答案和收藏会自动迁移到保留的原题。精选仍保留 300 道，已刷数量按去重后的题目统计。
- 全量题库与精选题共用答题记录，进入、刷新或翻题时自动跳过已刷题（包括答错题）；当前题答错后仍停留显示解析。答对后约 1 秒继续，全部刷完显示完成提示。收藏入口保留已刷题，供回看错题。
- 全量题库、精选题和收藏中的同一道题共用原网站解析，精选 300 题均有解析。另有 5 道全量题库题目在原网站也未提供解析，页面会明确提示并保留原题链接。
- 答案、收藏、题序和当前位置只保存在当前浏览器。清除浏览器网站数据可能会删除练习记录。
- 同一浏览器打开多个标签页时，只有一个标签页可以修改记录。其他标签页为只读；点击“接管练习”后，会先读取最新存档，原标签页随即停止写入。
- 在精选入口点“重新开始”，会清空这 300 道题在两个入口的答案并重排精选题序；在全量或收藏入口操作，会清空全部答案并重排两个入口的题序。收藏始终保留。

旧版记录会在读取、校验并成功保存为新版记录后清理。旧版全量题库的答案和收藏会迁移；更早版本保留收藏。若浏览器存储失败，页面会提示“当前进度尚未保存”，旧记录不会被清理。

## 开发与检查

项目使用 React、TypeScript 和 Vite。建议使用 Node.js 22，与部署环境保持一致。

```bash
npm test
npm run build
```

启动开发服务和构建时，会从 `data/题库.md`、`data/科目一_C1C2_原题精选300.md` 生成 `public/data/catalog.json`。生成结果只保存一份完整原题；精选集合只保存题号和展示章节。转换脚本会核对精选题与原题的题干、选项、答案、来源链接及配图，并检查题目数量和图片文件。不要手动修改生成的 JSON。

原始参考文件收录 1844 道题；网页排除原题 341、3554、3555，保留原题 342，再合并 191 份完整重复副本，实际练习 1650 道。原始题库及来源链接保留，精选题优先沿用原题号。题库内容的来源及授权说明见 [DATA-NOTICE.md](DATA-NOTICE.md)。

## 发布

推送到 `main` 后，GitHub Actions 会运行测试、构建并部署到 GitHub Pages。首次发布需在仓库 **Settings → Pages** 中将 **Source** 设为 **GitHub Actions**。
